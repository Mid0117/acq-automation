Decision protocol

  • Minimum sample: 200 sends per variant before reading any results.
  • Decisive lead: if one variant beats the others on contract rate by ≥ 3.0 percentage points at n ≥ 500/variant, declare winner.
  • Time cap: 30 days from first send. Declare based on data even if inconclusive — and note the inconclusion.
